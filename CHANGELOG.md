# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-22

Первый публичный выпуск.

### Добавлено

- Тёмный интерфейс в стиле WinUtil: две вкладки («Редактор», «Профили»), тёмный заголовок окна, иконки Segoe MDL2 Assets, статус-бар.
- Таблица записей `hosts`: статус, IP, домены; включение/отключение и удаление выбранной записи.
- Форма добавления записи с проверкой IP и домена, подтверждение по `Enter`.
- Массовое добавление списком: форматы `IP домен`, несколько доменов в строке, домен без IP, ссылки, IPv6, `[::1]`.
- Профили конфигураций: сохранение, активация, удаление, открытие папки профилей.
- Автоматическая резервная копия `hosts.bak` при первом запуске.
- Страховочные копии перед сбросом (`hosts.before-reset.bak`) и откатом (`hosts.before-restore.bak`).
- Сброс `hosts` к заводскому шаблону Windows.
- Атомарная запись через временный файл с сохранением кодировки и атрибута «только для чтения».
- Автоматическая очистка DNS-кэша после каждого изменения.
- Проверка прав администратора с перезапуском через UAC.
- Скрытие консольного окна PowerShell на время работы.
- Лог необработанных ошибок запуска в `HostsManager.error.log`.

### Исправлено

- Дубликаты записей считаются только внутри семейства адресов: IPv4 и IPv6 для одного домена разрешены одновременно.
- Закомментированные записи больше не блокируют добавление того же домена.
- Некорректные адреса (`fe80::1%12`, `::ffff:1.2.3.4`) отклоняются до записи в `hosts`.
- Строка, похожая на IP, но не распознанная как адрес, пропускается целиком и не превращается в домен.
- Ссылки `https://…` в массовом импорте больше не отбрасываются.
- `::` распознаётся как корректный IPv6-адрес.
